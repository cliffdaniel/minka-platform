Arquitectura de Minka

Servicios y conexiones definidos en Docker Compose con los puertos de desarrollo habituales.

Sesión y autorización

  • Web. Next.js envía las credenciales a NestJS y guarda el token en una cookie HttpOnly.
  • Mobile. La app llama a NestJS, guarda el token en el almacén seguro y lo envía en Authorization. En desarrollo, Android usa 10.0.2.2:4000 y el simulador iOS usa 127.0.0.1:4000.
  • Backend. NestJS valida la sesión y el rol antes de cargar el panel, administrar cuentas o publicar carreras. El backend local expone Swagger UI y el JSON de OpenAPI.

Organización del código

En Backend, los módulos agrupan el código por funcionalidad. El dominio define reglas y contratos, la aplicación aloja casos de uso, la infraestructura conecta TypeORM con PostgreSQL y las interfaces HTTP exponen los endpoints. Web y Mobile tienen sus propias capas de presentación y adaptadores de API.
